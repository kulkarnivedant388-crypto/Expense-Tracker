# 🎓 CampusCoin Tracker: Hostel & College Student Expense Manager

A full-stack, responsive web application paired with a robust **C++ core engine** designed specifically to help college students and hostel residents track daily expenses, manage mess fees, and split roommate bills effortlessly.

---
Live demo: https://kulkarnivedant388-crypto.github.io/Expense-Tracker/
---

## ✨ Key Features

* **Smart Expense Categorization**: Track spending across student-centric categories like *Mess & Canteen*, *Stationery & Prints*, *Hostel & Utilities*, and *Travel*.
* **Interactive Dashboard**: Real-time spending metrics and live graphical breakdown using **Chart.js**.
* **Hostel Student Toolkit**: Built-in utility to instantly calculate individual shares for shared room expenses and hostel bill splits.
* **CSV Persistence & Export**: Locally managed data flow with one-click CSV export capabilities.
* **C++ Architecture Core**: Designed with an underlying object-oriented C++ backend architecture demonstrating professional systems programming concepts.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, Modern CSS3, Tailwind CSS, JavaScript (ES6+)
* **Data Visualization**: Chart.js, FontAwesome
* **Core Logic / Engine**: C++ (`std::vector`, file handling streams, OOP structs)
* **Hosting & Version Control**: GitHub Pages & Git
